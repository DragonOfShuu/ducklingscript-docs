# VAR
`VAR` defines a new variable. Give the name, then the value, separated by a space.

:::info
`VAR` generally tries to reference any previous variables outside of a function. However, using `LOCALVAR`, you can ignore any outside variables and create a new one that is only accessible within the function.
:::

## Syntax
```
VAR <name> <value>
```

:::warning
Most commands do not evaluate variables by default, to bypass this behavior begin the command with a `$` like so: `$PRINT <varname>`. You can find more information about this in our [Dollar Sign Operator](/docs/guides/crash-course/command-types#dollar-sign-operator) documentation.
:::

## Example
```
VAR hello "Hi!"
$PRINT hello
PRINT hello
```
Output
```
Hi!
hello
```
