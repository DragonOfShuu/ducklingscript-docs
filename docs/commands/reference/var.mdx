# VAR
`VAR` defines a new variable. Give the name, then the value, separated by a space.

:::info
`VAR` generally tries to reference any previous variables outside of a function. Meaning Var acts similarly the the javascript `var`. 
However, using `LOCALVAR`, you can ignore any outside variables and create a new one that is accessible to the current function or block.
:::


## Syntax
```
VAR <name> <value>
```
Alt:
```
LOCALVAR <name> <value>
```

## Example
```
VAR hello "Hi!"
$PRINT hello
PRINT hello
```
Output
```
Hi!
hello
```

## Example with LOCALVAR
```
VAR x 5
VAR y 5

FUNCTION test_func
    REM x is only 10 now inside this function.
    LOCALVAR x 10
    REM y is 10 globally.
    VAR y 10

RUN test_func

REM X should be 5
$PRINT x
REM y should be 10
$PRINT y
```
Output
```
5
10
```
